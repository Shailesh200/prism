The `prism` MCP server is still one process. The Console is another door onto the same `start_job`.

- Compose a brief, pick a playbook, default to checkout. Chat still queues the same teammate.
- A finding can fill that brief instead of dying as a note.
- Focus shows billed in/out. Pulse stays wait and work.
- Prism still holds no OAuth tokens. Connectors stay in the host window.

Install remains `npx -y --prefer-online @repo-prism/mcp-server@latest`. Reload MCP after this publish. See [Usage](/docs/usage) and [Prism Dispatch](/docs/guides/dispatch).
