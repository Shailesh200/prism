Console skills and Pulse meters catch up with how jobs actually run.

- **Skills** keep version history. Revert, delete, or compare a snapshot. Edit can Update Skill with teammate instructions.
- **Pulse** paints pause as its own step. The status pill matches the last step. Worked time excludes pause.
- Running and paused bars use the same 6px height as done, failed, and cancelled.

Keep `@latest`. Reload MCP after this publish. See [Prism Dispatch](/docs/guides/dispatch).
