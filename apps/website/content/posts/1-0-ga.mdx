Prism 1.0 ships the local-first surfaces together: Core, CLI, MCP server, and
the VS Code / Cursor extension under one shared version.

What that means for you:

- Install once per surface and get the same answers everywhere
- Zero network for core analysis; consent-gated paths stay opt-in
- Docs and reference pages are generated from the same registries the binaries use
