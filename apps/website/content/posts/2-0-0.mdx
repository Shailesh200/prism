Prism 2.0 does two jobs for the coding agent you already use. Before it edits, Prism hands it the few files that matter. After it edits, Prism checks the change and gives a verdict. Everything runs on your machine.

## Start in one command

```bash
npm i -g @repo-prism/cli && prism start
```

`prism start` installs Prism for the agents it finds, indexes the repo, prints the top of the map and shows what to try. Install records what it writes; uninstall removes exactly that. After an upgrade, the next session brings Prism's hooks up to date and keeps a backup; your own hooks stay. See [Install](/docs/start/install#upgrade).

## Before the edit

- **Prepare** lists at most 3 files Prism is sure of, with nearby tests and one run command. Files that changed together in past commits rank into that list.
- The prompt hook adds that list to the agent's context inside a 1 s budget, in one Node process.
- `prism graph map` prints a compact map of the repo.

## After the edit

- **Receipts** lead with the verdict: SHIP, NOT PROVEN (with the cheapest command that would prove it) or NO-SHIP. Checks run your typecheck, lint and the tests the change reaches. See [Receipts](/docs/guides/receipt).
- **Review** (`guard_session` with `review: true`) says what is wrong, where, how to fix it, and the risk if you skip it.
- **Lenses** add nine data-backed checks. `prism review --lens qa` prints one lens's checks with evidence. See [Lenses](/docs/guides/lenses).

## Also new

- `habits` tool and `prism habit` for saved routines; one `prism` skill replaces five.
- `prism strength full|lite|off`, `prism stats`, `prism doctor --fix`.
- Every tool takes `maxTokens` (200–12,000). `test_impact` returns a ready command per package.

## Removed

The 1.x VS Code and Cursor extensions, app-shell, playground, Dispatch, and the 1.x tool names and environment variables. Installing 2.0 over 1.x removes 1.x data and keeps valid custom lenses and config keys.
