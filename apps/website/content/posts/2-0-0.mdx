Know before you ship. When Claude Code stops, Prism runs your checks on what changed and gives one verdict: SHIP, NOT PROVEN or NO-SHIP. Everything runs on your machine.

## Start in one command

```bash
npm i -g @repo-prism/cli && prism start
```

`prism start` finds your agents (Claude Code, Codex, opencode, Cursor), lists every config it will change and asks y/N. On yes, it backs up each file to `~/.prism-backups/<time in UTC>/`, sets each agent up and indexes the repo. In scripts, pass `--yes`. `--dry-run` only shows the list. `prism install <agent>` doesn't ask, but it backs up first and prints each file it wrote. Install records every write, and `prism uninstall` removes only what Prism added. See [Install](/docs/start/install).

## When the agent stops

- **Claude Code** gets a verdict in the chat when it stops: SHIP, NOT PROVEN (with the command that would prove it) or NO-SHIP.
- **Codex and opencode:** the verdict comes with your next receipt.
- **Cursor** is set up for receipts. Ask the agent for one.
- **Your own checks.** Prism reads your package.json and runs your scripts and the tests the change reaches. `prism receipts show` lists each check and its result. See [Receipts](/docs/guides/receipt).

## Updating

Nothing updates by itself. To update, run `npm i -g @repo-prism/cli@latest`, then `prism upgrade`. It lists the config changes and asks y/N. Prism tells you when a new version is out, and when its Claude Code hooks are out of date it prints one line asking you to run `prism doctor --fix`.

## Also new

- `habits` tool and `prism habit` for saved routines; one `prism` skill replaces five.
- `prism strength full|lite|off`, `prism stats`, and `prism doctor --fix`, which asks y/N and backs up first.
- `prism graph map` prints a compact map of the repo.
- Every tool takes `maxTokens` (200–12,000). `test_impact` returns a ready command per package.

## Removed

The 1.x VS Code and Cursor extensions, app-shell, playground, Dispatch, and the 1.x tool names and environment variables. Installing 2.0 over 1.x moves your 1.x data to `~/.prism-backups/<time in UTC>/1x/`. Valid custom lenses and config keys carry over.
