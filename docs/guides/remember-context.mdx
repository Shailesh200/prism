> Save a fact once. Prepare hands it back before the next edit. Prism will not
> write an AGENTS.md into your git tree.

Two small stores sit next to Prepare. They are local. They are not a model.

## Memories

A memory is a short note about this repository: a decision, a rule, a warning.
Save it from the terminal:

```bash
prism remember "use lruCache, never a bare Map" --symbol lruCache
prism remember "generated clients live here; do not edit by hand" --path src/gen
prism memories
prism forget lruCache
```

| Command | What it does |
|---|---|
| `prism remember "<note>"` | Saves a note. `--symbol` or `--path` anchors it. |
| `prism memories` | Lists the notes for this repository, with their ids. |
| `prism forget <id or text>` | Removes notes by id, or every note whose text matches. |

Notes are stored in:

```text
~/.prism/workspaces/<key>/memory.json
```

They are never written into the repository.

`prepare_change` includes anchored notes for the files in its pack, next to
ADR / `WHY:` / `NOTE:` hits. See [Prepare a change](/docs/guides/prepare-a-change).

If you rename an anchored symbol with Prism's rename in the IDE, the note
moves with it.

There is no MCP tool for memories. To save one from chat, ask your agent to
run `prism remember`.

## Living AGENTS.md

`prism agents-md` writes a contributor sheet from the index: features, import
cycles, test locations, owners. **No LLM prose.**

```bash
prism agents-md generate
prism agents-md check
```

The file lives only at:

```text
~/.prism/workspaces/<key>/agents.md
```

It is **never** written into the repository, never into `{repo}/.prism/*.md`,
and never copied to `CLAUDE.md`. If this repo already has an `AGENTS.md`,
generate may *read* it as input. It will not overwrite it.

`check` compares the claims to a fresh index. CI can fail when a claim went
stale.

MCP: `agents_md` with `action=generate` or `check`, opt-in through
`extraTools` in `~/.prism/config.json`. Read `prism://agents-md` for the current text
without regenerating.

## When this is wrong

- Do not copy `~/.prism/.../agents.md` into the repo or offer to commit it.
- A memory is a standing fact, not a log of the session. Keep it short.
- Notes that are not anchored to a symbol or path will not move on rename.
