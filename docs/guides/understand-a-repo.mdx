> Learn what a repository is built from and where to start reading.

<Tabs groupId="surface" items={['CLI', 'AI agent']} persist>
  <Tab value="CLI">

```bash
cd your-repo
prism doctor
prism overview
```

  </Tab>
  <Tab value="AI agent">

Ask the agent: "Orient me to this repository — what is it built with and
where should I start reading?"

Optional prompt: `orient` (calls `repository_overview`).

  </Tab>
</Tabs>

## What you get back

- **DNA / stack** — frameworks, domains (frontend, backend, data,
  infrastructure), confidence and evidence per signal.
- **Landmarks** — entrypoints and anchors a human would open first.
- **Graph** — use `graph` (mode `neighbors` or `explain`) to walk outward from
  a landmark.

## When this is wrong

- Doctor chose the wrong workspace → pass `--workspace` or set
  `PRISM_WORKSPACE`.
- Low-confidence stack signals (`dependency only`) are leftovers, not active
  tooling — check the evidence.
- Odd file counts → excludes or generated output; see
  [troubleshooting](/docs/help/troubleshooting).
