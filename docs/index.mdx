Prism is software intelligence for coding agents. It runs on your machine.
Prepare names the files to edit, the tests to run, and code to reuse. A lens
sets how the agent works: Dev for house style and blast radius, QA and
Architect for the change. Review reads the change and returns Critical, High,
Low, and Nit findings, then a Receipt: SHIP, NOT PROVEN, or NO-SHIP. Analysis
has no model. Your agent makes the edits.
