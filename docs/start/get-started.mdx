Follow the steps below. You do **not** need to clone the Prism GitHub repo —
published packages are enough.

## 1. Prerequisites

<Steps>
<Step>

**Node.js 26+** — check with `node -v` (should start with `v26`).

</Step>
<Step>

**A project folder** — TypeScript / JavaScript repository. Open or `cd` into it.
Git is recommended but not required.

</Step>
<Step>

**Pick one surface to start** — you can add others later. They share the same
engine.

</Step>
</Steps>

## 2. Install a surface

Choose the lane that matches how you work:

<Tabs items={["CLI", "IDE (VS Code / Cursor)", "AI agents (MCP)"]}>
<Tab value="CLI">

Terminal and CI. Fastest way to try Prism.

<Steps>
<Step>

Open a terminal **inside your project**:

```bash
cd /path/to/your/project
```

</Step>
<Step>

Check the environment (workspace resolves from the git root):

```bash
npx -y @repo-prism/cli doctor
```

</Step>
<Step>

Run your first analyses:

```bash
npx -y @repo-prism/cli dna
npx -y @repo-prism/cli health
```

</Step>
<Step>

Optional — install globally:

```bash
npm install -g @repo-prism/cli
prism doctor
```

</Step>
</Steps>

Full detail: [CLI install](/docs/cli/install) · [CLI usage](/docs/cli/usage)

</Tab>
<Tab value="IDE (VS Code / Cursor)">

Visual map, health, and blast radius in the editor.

<Steps>
<Step>

Install the extension:

- **VS Code** — search **Prism**, or open the
  [Marketplace](https://marketplace.visualstudio.com/items?itemName=prismhq.repo-prism)
- **Cursor** — search **Prism**, or
  [Open VSX](https://open-vsx.org/extension/prismhq/repo-prism)

</Step>
<Step>

**File → Open Folder…** on your project (not a single file).

</Step>
<Step>

Command Palette → **Prism: Open Prism**. Wait for indexing in the status bar.

</Step>
</Steps>

Full detail: [IDE install](/docs/ide/install) · [IDE usage](/docs/ide/usage)

</Tab>
<Tab value="AI agents (MCP)">

Give Cursor, Claude Code, Claude Desktop, or Codex structural tools.

<Steps>
<Step>

**Claude Code** (from your project directory):

```bash
claude mcp add prism -- npx -y @repo-prism/mcp-server
```

</Step>
<Step>

**Cursor** — create `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "prism": {
      "command": "npx",
      "args": ["-y", "@repo-prism/mcp-server"]
    }
  }
}
```

Then Settings → MCP → enable **prism** (~28 tools).

</Step>
<Step>

Ask the agent something structural, e.g. “What is this repository?” or “What
breaks if I change `src/index.ts`?”

</Step>
</Steps>

Also: [Claude Desktop / Codex](/docs/mcp/install) · [MCP usage](/docs/mcp/usage)

</Tab>
</Tabs>

## 3. Confirm it works

| Surface | You should see |
|---|---|
| CLI | `doctor` prints a workspace path; `dna` / `health` print reports |
| IDE | Prism panel opens after indexing |
| MCP | ~28 tools listed; agent answers with repository structure |
