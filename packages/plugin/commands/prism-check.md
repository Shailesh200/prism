---

Report what depends on whatever the user named after the command — a file, a
symbol, or the code currently in focus.

Follow the `prism-safe-change` skill: `blast_radius` for an edit,
`rename_impact` for a rename, `safe_delete` for a removal.

Say plainly whether the change looks contained or far-reaching, and name the
call sites that have to move together. Do not make the edit unless the user
asked for it.
